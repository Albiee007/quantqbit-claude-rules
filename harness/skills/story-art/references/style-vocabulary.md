# Style vocabulary

A range of render styles to draw concepts from. **There is no default.** The illustration concept picks one (or a blend) for the direction's mood, audience and existing identity; the owner approves it. Concepts in one round should come from different families below. Phrases are prompt starting points, not formulas: adapt them to the provider.

| Family | Style | Prompt phrase | Suits (mood levers) | Watch for |
|---|---|---|---|---|
| Flat and graphic | Flat vector | "flat vector illustration, clean shapes, limited palette" | minimal, product, contemporary | generic "corporate Memphis" figures; give it a point of view |
| | Swiss / geometric poster | "geometric poster illustration, bold shapes, strong grid, sparse detail" | geometric, serious, editorial | can feel cold for caring products |
| | Mid-century modern | "mid-century modern illustration, textured flat shapes, retro palette" | classic, warm, playful | cliché if the brand is not retro |
| | Monoline | "monoline illustration, single-weight outlines, spot colour fills" | minimal, calm | thin lines vanish at small sizes |
| Print and craft | Risograph | "risograph print style, two-colour overlap, grain, slight misregistration" | warm, editorial, playful | colour count; keep to the palette |
| | Linocut / woodcut | "linocut print illustration, carved texture, bold contrast" | organic, classic, serious | heavy at small sizes |
| | Paper cut / collage | "layered paper-cut illustration, soft shadows between layers" | playful, organic, warm | busy backgrounds |
| | Halftone pop | "halftone print illustration, dot shading, bold outlines" | energetic, playful | noisy behind text |
| Painterly | Gouache | "gouache illustration, opaque matte paint, visible brushwork" | warm, calm, organic | muddy shadows; ask for clean light |
| | Watercolour | "watercolour illustration, soft washes, paper texture, white space" | calm, organic, classic | low contrast for overlaid text |
| | Ink and spot colour | "ink line illustration with one spot colour" | editorial, serious, minimal | needs a confident accent |
| | Crayon / children's book | "crayon and pencil illustration, hand-drawn texture" | playful, warm | can read as childish |
| Dimensional | Clay 3D | "stylised 3D clay render, soft materials" | playful, product | very common in app marketing; choose it on purpose |
| | Low-poly 3D | "low-poly 3D illustration, faceted shapes, soft gradients" | geometric, energetic | dated if overdone |
| | Isometric | "isometric illustration, 30-degree axes, tidy detail" | geometric, product, serious | small figures; explains systems well |
| Photographic | Still life | "photographic still life, studio light, real materials" | serious, classic, editorial | props must be generic and unbranded |
| | Photo collage | "editorial photo collage, cut-out shapes, flat colour blocks" | editorial, energetic | no real people's likeness |
| Technical and other | Blueprint | "blueprint technical drawing style, line work on a tinted ground" | geometric, serious | dense line work at small sizes |
| | Pixel art | "pixel art illustration, limited palette, crisp pixels" | playful, contemporary | export without smoothing |
| | Abstract shapes | "abstract composition of shapes in the brand palette, no figures" | minimal, geometric | must still map to a feature (a metaphor) |

## Picking for a concept
- Start from the direction's mood axes and keywords ([mood-levers](../../creative-direction/references/mood-levers.md)), the audience and where the art is shown (a 640 px card needs bolder shapes than a hero).
- Respect `keep`: if the product already has an illustration style the owner keeps, concepts vary the story world and composition, not the style.
- Lighting and background come with the style: say them explicitly in the style bible ("overcast daylight", "flat warm ground", "night with a single lamp").
- Palette: token references from the direction, named in the prompt with their hexes. Generated pixels won't match tokens exactly; that's fine for illustration.
