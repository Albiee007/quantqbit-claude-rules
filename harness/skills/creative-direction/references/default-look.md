# The harness 1.6 default look (discussion signals)

Up to 1.6, the harness's templates carried one look, so projects that didn't change them looked alike. `direction.py signals` and `concept check` point out where an asset still repeats it. **A signal is not a defect.** If the direction keeps a choice (`keep`), or the owner made it on purpose, it stays.

| Signal id | What it means |
|---|---|
| `harness:color` | a colour within ΔEOK 0.03 of a 1.6 default: indigo `#2a1bb0` `#3525cd` `#5b4ff0`, mint `#9ff3cf`, lavender `#dcd9ff`, `#464555`, bezel `#0e0f1c`, story-art `#1d0f8a` `#c3c0ff` |
| `harness:inter-800-tight` | captions in Inter 800 with tight tracking |
| `harness:centred-phone` | every frame: centred caption on top, framed phone below (the only 1.6 classic layout) |
| `harness:diagonal-3-stop` | a 145–170° three-stop diagonal gradient |
| `harness:watermark-glyphs` | faint glyphs at fixed spots behind store frames |
| `harness:finance-props` | coins, chips, receipts, calendars outside a finance app |
| `harness:og-1.6-template` | a copy of the 1.6 Open Graph template |
| `harness:circle-check-logo` | the 1.6 logo placeholder (a circle with a check) |
| `harness:flat-icon-0.6` | a glyph centred at 0.6 on a flat colour |
| `harness:soft-clay-3d`, `harness:dark-indigo-backdrop` | the 1.6 story-art example's render style and backdrop |

How to use them: in critique, name the signal and ask whether it is a choice. In review, note any that crept in without one.
