## Inaccessible standards
The following were not read. Nothing in this skill should be taken as a statement of their contents; where a claim touches them, it comes from the named free or secondary source.
- **CIE 015:2018 Colorimetry** (paid). Observer and illuminant statements come from the CIE data tables, CSS Color 4 and Wikipedia.
- **CIE 159:2004 (CIECAM02)** and **CIE 116-1995 (ΔE94)**. Mentioned by name only.
- **IEC 61966-2-1 (sRGB)** (paid). The sRGB transfer function is taken from CSS Color 4 sample code and the WCAG 2.2 definition.
- **ISO 3664 (viewing conditions)**, **ISO 13655 (measurement conditions)**. M0/M1 summaries from Cheydleur's ICC presentation; the 2° observer for graphic-arts measurement is general practice, not verified.
- **ISO 12647 (print process control, incl. 12647-2 tolerances)**. Named only; contents not verified. Printing-condition names come from the ICC registry.
- **ISO 15076-1**. Relation stated from ICC.1:2022's own text.
- **ISO 18619 (black point compensation)**. Named only.
- **SMPTE ST 2084 (PQ)**. Facts from CSS Color HDR.
- **ITU-R BT.709, BT.1886, BT.2020, BT.2100, BT.2408 full texts**. Only reference pages read; technical statements from CSS Color 4 / CSS Color HDR or general knowledge flagged as such.
