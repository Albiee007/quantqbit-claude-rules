# Brand asset matrix

Export everything from the SVG or HTML masters, never by resizing PNGs. Store sizes come from the `store-submission-precheck` skill's `references/store-specs.md` (mobile projects), and app icons from the `app-icons` skill.

| Asset | Size | Format | Source | Notes |
|---|---|---|---|---|
| Mark (master) | vector, 1024 viewBox | SVG | `brand/mark.svg` | Plus mono and reverse variants |
| Wordmark | vector | SVG | `brand/wordmark.svg` | Text converted to outlines. Licence check on the font |
| Horizontal lockup | vector | SVG | `brand/lockup-horizontal.svg` | Mark + wordmark, clear space = the height of the mark's inner shape |
| Stacked lockup | vector | SVG | `brand/lockup-stacked.svg` | For square spaces |
| Mark PNGs | 2048, 1024, 512, 256 px | PNG with alpha | `export_svg.py --size` | 2048 feeds `app-icons` |
| Splash image (light) | 1024 × 1024 mark on transparency | PNG | mark | Expo `expo-splash-screen` `image` + `backgroundColor` |
| Splash image (dark) | 1024 × 1024 | PNG | reverse mark | `dark: { image, backgroundColor }` |
| Social / Open Graph | 1200 × 630 | PNG or JPEG, flattened | `templates/og-image.html` | Also the Twitter/X `summary_large_image` |
| Play feature graphic | 1024 × 500 | PNG, no alpha | `store-mockups` feature graphic | Use the store-mockups kit when it includes a phone |
| Email header | 1200 × 300 | PNG, flattened | HTML like og-image | Keep text large enough for mobile mail |
| Promo banner | as the campaign needs | PNG, flattened | HTML like og-image | Web and ads, never inside store screenshots |
| Favicon / PWA | 16–512 | PNG / ICO | `app-icons` | Generated by `make_icon_set.py` |

## Colour and type tokens
Write the brand tokens once, e.g. `brand/tokens.json` (DTCG format: primary, on-primary, accent, neutral scale, and fonts with their licences). Link the app theme and the web CSS to it, and have the ui-ux skill's token rules consume it. Every asset above uses only these tokens.
